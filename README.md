# 💻 Muhammad Fakhir Andito - Personal Portfolio

A digital workspace and personal portfolio showcasing my journey in Information Systems, tech exploration, and creative digital manipulation. Designed with a utilitarian dark mode aesthetic and bento grid layout.

## ✨ Tech Stack & Features

*   **Framework:** Next.js (App Router)
*   **Styling:** Tailwind CSS v4 (Custom Utilitarian Dark Theme)
*   **Animations:** Framer Motion
*   **Architecture:** Bento Grid UI, Responsive Design, Semantic HTML

## 🚀 Highlights

*   **Cinematic & Utilitarian Vibe:** Custom dark mode interface with neon cyan accents.
*   **Smooth Interactions:** Integrated with Framer Motion for precise, hardware-like page transitions and scroll reveals.
*   **Project Showcase:** Interactive case studies ranging from academic system analysis to AI image generation.
